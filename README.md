# 大狗叫内核

纯 TypeScript 编写的浏览器逻辑内核，零第三方依赖，MIT 协议开源。

它不是渲染引擎，而是负责浏览器"大脑"逻辑的独立内核层。它以 **Chromium** 作为底层渲染引擎，任何宿主环境（如 Electron、CEF 容器、自研客户端等）都可以通过加载它获得完整的浏览器核心逻辑能力。

> A pure TypeScript browser logic kernel with a self-developed extension store ecosystem. Zero dependencies, MIT licensed. Relies on Chromium for rendering.

---

## 一、这是什么

浏览器由两大部分组成：**渲染引擎**（负责把网页画成屏幕上的像素）和**逻辑内核**（负责地址栏解析、导航决策、历史、书签、隐私策略、扩展调度这些“大脑”工作）。

大狗叫内核**只做后者**。它本身**不包含渲染引擎**，不直接解析 HTML 或绘制像素。它的渲染能力**依赖于宿主调用的 Chromium**（或其他外部渲染容器）来完成。

你可以把它理解为一个独立运行的“浏览器大脑”，通过接口去指挥 Chromium 这个“躯壳”干活。这样做的好处是：

- **逻辑与渲染解耦**：渲染交给 Chromium，逻辑由大狗叫内核接管，架构清晰。
- **可审计**：约 300 行核心源码，逻辑透明，便于审查与改造。
- **零依赖**：不引入任何第三方 npm 包，不存在供应链风险。
- **可移植**：只要能实现宿主通信接口（Host 接口），同一份内核可以桥接到各类渲染容器中。

## 二、文件组成

| 文件 | 说明 |
|------|------|
| `kernel.ts` | 逻辑内核源码（约 300 行），无第三方依赖。编译产物 `kernel.js` 供浏览器界面直接引用，通过 `window.DGBrowser` 暴露接口。渲染动作需宿主交由 Chromium 处理。 |
| `extensions-runtime.ts` | 自研扩展运行时，与宿主解耦。宿主只需实现 `Host` 接口（标签查询、脚本注入、消息通道、弹出窗、后台承载）即可接入。 |
| `run-tests.mjs` | 单元测试，共 21 项，覆盖地址解析、搜索引擎路由、恶意站点检测、扩展清单解析等核心逻辑。 |

## 三、逻辑内核能力

### 1. 地址与搜索智能解析

输入框里输入的内容，内核会自动判断是网址还是搜索词：

- 合法 URL（含协议、域名、IP、localhost、端口）直接导航
- 非 URL 内容按搜索词处理，路由到用户选定的搜索引擎
- 内置 6 大搜索引擎路由：**必应、百度、谷歌、搜狗、360、夸克**
- 支持用户自定义搜索引擎与默认引擎切换

### 2. 安全防护

- **恶意站点启发式检测**：基于域名特征、路径模式、可疑参数等启发式规则识别风险站点。设计原则是“宁可漏报、不误杀”，避免干扰正常浏览。
- **跟踪器黑名单拦截**：内置跟踪器域名黑名单，命中即拦截。
- **HTTPS 强化**：对可升级站点优先使用 HTTPS，降低明文传输风险。

### 3. 本地数据持久化

历史记录、书签、下载记录、设置项全部保存在本地，**数据不上传**。内核不包含任何遥测或云端同步逻辑，用户数据留在用户设备上。

### 4. 隐私能力

- 隐私统计：记录拦截次数、拦截类型等本地统计。
- 无痕会话隔离：无痕模式下的历史、缓存、会话数据与正常模式隔离，退出即清理。

## 四、扩展系统能力

扩展运行时是自研实现，不基于 Chromium 或任何第三方扩展框架。

### 1. 兼容性与安装形态

- 兼容 **Chrome 扩展商店**与 **Edge 扩展**，支持 **Manifest V2 / V3**。
- 兼容 **火狐 WebExtensions** 子集。
- 支持三种安装方式：目录安装、`.crx` 安装（自动剥离 Cr24 头，解析 v2 / v3）、`.zip` 安装。

### 2. 已实现 API

| API | 已实现能力 |
|-----|-----------|
| `chrome.runtime` | `sendMessage` / `onMessage` |
| `chrome.storage.local` | `get` / `set` / `remove` / `clear` |
| `chrome.tabs` | `query` / `sendMessage` |
| `chrome.action` | `onClicked` / `default_popup` |
| `content_scripts` | 注入，matches 通配含 `<all_urls>`，支持 js / css、`run_at` |
| `background` | 双路径：MV2 `scripts` 数组 / MV3 `service_worker` |

### 3. 自研扩展商店生态（全套后端与前端支持）

除了本地加载扩展，本项目还配套了**完全自研的扩展商店系统**，为浏览器提供完整的生态闭环：

- **用户系统**：支持用户登录、注册。
- **开发者中心**：开发者可以上传、发布、管理自己的扩展程序。
- **评价与评分**：支持用户对扩展进行评论和星级评分。
- **分发与管理**：用户可在商店内直接搜索、浏览并一键安装扩展。

### 4. 宿主解耦设计

扩展运行时通过 `Host` 接口与宿主通信。宿主只需实现以下能力，即可接入扩展系统：

- 标签查询
- 脚本注入
- 消息通道
- 弹出窗
- 后台承载

这意味着扩展运行时和商店生态可以脱离 Chromium，跑在任意自研浏览器里。

---

## 五、如何接入

1. 编译 `kernel.ts` 得到 `kernel.js`（或直接使用仓库中的编译产物）。
2. 在你的宿主软件中（如 Electron、CEF 容器等），引入 `kernel.js`，通过 `window.DGBrowser` 调用内核接口。
3. 宿主负责集成 Chromium 渲染引擎，并将标签控制、脚本注入、消息通道等能力通过 `Host` 接口桥接给扩展运行时。
4. 大狗叫内核接管所有的逻辑路由（地址解析、搜索、安全过滤、扩展调度），然后指挥 Chromium 进行具体的页面加载和渲染。
